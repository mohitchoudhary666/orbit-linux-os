# Security policy

Orbit Linux is an educational QEMU image, not a hardened general-purpose operating system. Its default root account has no password for local emulator access. The image is intended to run offline and does not enable an SSH server.

Do not expose the image to untrusted networks or use it for sensitive workloads. Report security issues privately to the repository owner through GitHub rather than posting exploit details publicly. Include the affected commit, reproduction steps, and impact when safe to do so.
